# Expo HAS CHANGED

This project targets Expo SDK 57. Its APIs have changed significantly since older
training data. Do NOT rely on memory for an Expo/React Native API you are not
fully certain about — fetch the specific page at
https://docs.expo.dev/versions/v57.0.0/ for that API before using it. Do not
fetch the docs site speculatively or for code that doesn't touch an Expo API.
